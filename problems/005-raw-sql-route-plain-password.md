# 005: route تجريبي فيه كلمة سر نص عادي

- **الحالة:** ⏳ مفتوحة (الكود معلّق حالياً، فمش خطر توا)
- **الخطورة:** متوسطة
- **الملف:** `routes/api.php`

## شن المشكلة
```php
// return DB::statement("INSERT INTO users (...) VALUES ('John Doe', 'john@xample.com', 'supervisor', 'password')");
```

## ليش تأثر لو تفعّله
- `DB::statement` ما يمرّش على `casts` الموديل، فكلمة السر تنحفظ **نص عادي** بدون تشفير.
- `Route::get("/")` بدون حماية: أي حد يفتح الرابط يضيف مشرف.
- القيم مكتوبة داخل الـ SQL. لو تبدّلت بقيم جاية من المستخدم يصير SQL injection.

## كيف تتصلح
- استعمل `User::create()` (يشفّر تلقائياً)، أو `Hash::make()` مع `?`.
- إنشاء المستخدمين يكون `POST` ومحمي (مشرف مسجل دخول)، مش `GET` مفتوح.
- أو امسح الـ route التجريبي لما تخلص منه.
